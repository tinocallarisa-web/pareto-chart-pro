License validation:
Uses official Microsoft IVisualLicenseManager API. No external server.
Plan ID: pareto-chart-pro-tcviz
Resolution is async and does not block initial render.

Free tier (no license required):
- Fixed 20% bins (5 bars showing top to bottom entities)
- Full Pareto chart with cumulative % line + interactive dots with tooltips
- Up to 2 configurable reference lines (default: 80%)
- Drilldown / hierarchical view (via standard Power BI drill buttons)
- Bar color, opacity, axis and cumulative line styling
- Cross-filtering (filter-out via click, filter-in via highlights)
- Tooltips on bars and cumulative dots
- Report/canvas tooltips support
- High contrast mode support
- Context menu on right-click

Pro tier (requires active AppSource license):
- Custom bin size: 1-20% (default 5% = 20 bars)
- Outlier filter: exclude top/bottom % of entities
- Bar border color and width
- Bar gap control
- Value labels on bars (font size, color, show % sign)
- Third reference line
- All Free features included

Network access:
- IVisualLicenseManager: standard Microsoft licensing API call only
- No other external network requests
- No data leaves the Power BI report

Formatting Pane:
- Migrated to getFormattingModel() using powerbi-visuals-utils-formattingmodel
- Pro-only slices hidden via slice.visible = false when Free tier
