License validation:
Uses official Microsoft IVisualLicenseManager API. No external server.
Plan ID: pareto-chart-pro-tcviz
Resolution is async and does not block initial render.

Both Active and Warning states are accepted as a usable licence, per the
licensing API documentation ("only the active and warning states represent a
usable license"). Warning is a grace period, so a paying customer keeps their
features while a payment issue is resolved.

isLicenseUnsupportedEnv and isLicenseInfoAvailable are both honoured. In
Publish to Web, embedded, national clouds, PDF/PPT export, or when the user is
offline or not signed in, a Pro customer legitimately reads as Free — in those
cases the visual renders the Free experience but never prompts to purchase.

Free tier (no license required):
- Fixed 20% bins (5 bars showing top to bottom entities)
- Full Pareto chart with cumulative % line + interactive dots with tooltips
- Up to 2 configurable reference lines (default: 80%)
- Drilldown / hierarchical view (via standard Power BI drill buttons)
- Bar color, opacity, axis and cumulative line styling
- Cross-filtering (filter-out via click, filter-in via highlights)
- Tooltips on bars and cumulative dots
- Report/canvas tooltips support
- High contrast mode support
- Context menu on right-click

Pro tier (requires active AppSource license):
- Custom bin size: 1-20% (default 5% = 20 bars)
- Outlier filter: exclude top/bottom % of entities
- Bar border color and width
- Bar gap control
- Value labels on bars (font size, color, show % sign)
- Third reference line
- All Free features included

Network access:
- IVisualLicenseManager: standard Microsoft licensing API call only
- No other external network requests
- No data leaves the Power BI report

Formatting Pane:
- Migrated to getFormattingModel() using powerbi-visuals-utils-formattingmodel
- Pro slices are visible to every user and each carries "(Pro)" in its display
  name. They were previously hidden from Free users, which meant the paid
  features could not be discovered at all.

Licensing UX:
- The visual displays no licensing UI of its own. A Free-tier caption that read
  "upgrade to Pro..." was removed in 1.4.0.0.
- When a Free user explicitly sets a Pro property, the visual calls
  notifyFeatureBlocked() so Power BI shows its own predefined banner, as
  required by the licensing API guidance.
- Intent is detected from dataView.metadata.objects, which carries only
  properties the user set explicitly, so the notification never fires on
  defaults. It is raised once per distinct set of attempted features.

9. Right-click a bar: Power BI context menu appears
10. Add hierarchy to Entity field: drill buttons appear in visual header
    Drill down one level: Pareto recalculates for drilled data
11. Reference line at 80% (default): horizontal + vertical dashed crosshair,
    label "80%" on left Y-axis, bin label shown at top of vertical line
12. Change any "(Pro)" setting — for example set Bin size % to 10, or switch on
    "Show line 3". The chart keeps rendering the Free result, and Power BI's own
    "feature blocked" banner appears with the purchase path. Changing a non-Pro
    setting afterwards does not re-raise it.
