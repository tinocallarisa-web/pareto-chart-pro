Quick Start

1. Add the visual to your report

In Power BI Desktop, go to the Visualizations pane → click the three dots → Get more visuals → search for Pareto Chart Pro.

2. Bind your data

Drag a category field (e.g. Customer, Product, SKU) into Entity and a numeric measure (e.g. Revenue, Quantity) into Value. The chart renders automatically with bars sorted from highest to lowest contribution and a cumulative line.

3. Interpret the chart

The left Y-axis shows each bin's share of the total. The right Y-axis shows the cumulative percentage. The default reference line marks the 80% threshold — the point where the top entities collectively reach 80% of the total value.

4. Use drilldown

Add a hierarchy field (e.g. Category > Subcategory > SKU) to the Entity well. Use the drill buttons in the visual header to navigate levels.

FAQ

Why are my bars not sorted from highest to lowest?

The visual always sorts automatically — you do not need to sort your data beforehand. If bars seem unsorted, check that:

  • The Value field contains a numeric measure (not a text field or a calculated column).
  • The measure resolves to a positive number for each row. Rows with null or zero values may be ignored.
  • You are not applying a report-level sort that conflicts with the visual's internal sort.
How do I set the 80/20 threshold?

Line 1 is pre-configured to 80% by default. You can change it in Format Pane → Reference Lines → Line 1 threshold. Set the value to any cumulative percentage between 1 and 99. You can add a second line (e.g. 60%) and a third line at any value (Pro only).

Why does the visual show "Free: 10% bins" even after buying Pro?

License validation happens asynchronously after the visual first renders. Wait a moment after opening the report — the badge should disappear automatically once the license is confirmed. If it persists:

  • Make sure you are signed into Power BI with the Microsoft account that purchased the license.
  • Check that the license is active in My Account → Licenses in the Microsoft 365 admin center.
  • Try closing and reopening the report.
How does drilldown work?

Add a hierarchy to the Entity field well (e.g. Product Category → Product Subcategory → SKU). The drill buttons appear in the visual header. Click the single arrow to drill down one level across all bins, or click a specific bar and use the fork arrow to drill into that selection. The Pareto recalculates automatically at each level.

Can I use conditional formatting on bar colors?

Yes. In the Format Pane → Pareto → Bar color, click the fx button to open the conditional formatting dialog. You can apply rules based on field values, percentile ranges, or gradient scales — the same as any native Power BI visual.

The chart looks correct in Power BI Desktop but shows Free behavior in the Service

This is usually a license assignment issue. Make sure the Pro license is assigned to the user account that is viewing the report in Power BI Service, not only to the account that published it. License assignment is managed in the Microsoft 365 admin center.

What is the maximum number of data rows the visual supports?

The visual requests up to 30,000 rows from the data model. Because the visual groups entities into bins, even large datasets render cleanly — a dataset with 10,000 SKUs at 10% bin size produces only 10 bars. For datasets larger than 30,000 rows, pre-filter with slicers or report filters before connecting to the visual.

Does the visual support high contrast mode?

Yes. When Windows or Power BI high contrast mode is active, the visual automatically uses system foreground and background colors for all chart elements — bars, lines, axes, dots, and reference lines — to meet accessibility requirements.

Does the visual send my data anywhere?

No. All data processing happens locally inside Power BI. The only external network request is the license validation call to the Microsoft licensing API (IVisualLicenseManager) — this is the standard Power BI mechanism and shares no report data. See the Privacy Policy for full details.
