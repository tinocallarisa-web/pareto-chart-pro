RESUBMISSION - 1200.1.1.4 (package.json)
1.3.0.1 was rejected with "typescript v3.0.0 or higher does not appear to be
present". It compiled because npx fetches TypeScript on demand, but it was not
declared. typescript ^5.9.3 is now a devDependency, package-lock regenerated.
Build: npm install && npm run package.

TESTING - FREE (no licence)
1. Bind a dimension to Entity and a measure to Value: 5 bars, cumulative line,
   80% reference line.
2. Click a bar to cross-filter; Ctrl+click adds.
3. Tab in, arrows move, Enter selects, Escape clears, Shift+F10 opens the menu.
4. Pareto > Bar color > fx opens conditional formatting; the Threshold Colors
   card colours bars by cumulative threshold.
5. Change any setting marked "(Pro)", e.g. Bin size %: the chart keeps the Free
   result and Power BI's "feature blocked" banner appears. A licence icon also
   shows while Pro settings are set without one. Both clear once it resolves.

TESTING - PRO (active plan)
6. Bin size % to 5 gives 20 bars. Check outlier trimming, value labels, the 3rd
   reference line, bar border and gap. No banner or icon appears.

PRIVACY / NETWORK
No external calls: no telemetry, analytics, CDN or endpoints. Rendering is all
local. The only host API is IVisualLicenseManager (getAvailableServicePlans),
carrying no report data. No file access, localStorage or cookies. One property
is persisted, general.filter, via host.applyJsonFilter.

LICENSING
Plan ID pareto-chart-pro-tcviz. Deferred with setTimeout(0) after first render,
so it never blocks painting; on failure the visual stays Free. Active and
Warning are both accepted. isLicenseUnsupportedEnv and isLicenseInfoAvailable
are respected, so a Pro user in Publish to Web, embedded or PDF export is never
prompted to buy. No licensing UI of our own, only platform notifications.
Production state: isPro from the licence manager, DEV_MODE false.

FREE: the complete Pareto, minus the Pro items.
PRO: bin size 1-20%, outlier trimming, value labels, 3rd reference line, bar
border and gap.
