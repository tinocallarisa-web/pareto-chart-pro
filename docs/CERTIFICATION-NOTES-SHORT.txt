WHY THIS RESUBMISSION
Replaces 1.4.0.0. Licence fix: spIdentifier is the full Service ID
(publisher.offer.plan); the check now accepts one ending in
".pareto-chart-pro-tcviz". package.json version is now valid semver (1.4.1).

TESTING - FREE (no licence)
1. Bind a dimension to Entity and a measure to Value: 5 bars, cumulative line,
   80% reference line.
2. Click a bar to cross-filter; Ctrl+click adds.
3. Tab in, arrows move, Enter selects, Escape clears, Shift+F10 opens the menu.
4. Pareto > Bar color > fx opens conditional formatting; Threshold Colors card
   colours bars by cumulative threshold.
5. Change a setting marked "(Pro)", e.g. Bin size %: the chart keeps the Free
   result and Power BI's "feature blocked" banner appears, plus a licence icon
   while Pro settings are set. Both clear once a licence resolves.

TESTING - PRO (active plan)
6. Bin size % to 5 gives 20 bars. Check outlier trimming, value labels, the 3rd
   reference line, bar border and gap. No banner or icon appears.

PRIVACY / NETWORK
No external calls, telemetry, CDN or endpoints. The only host API used for
licensing is IVisualLicenseManager, carrying no report data. No file access,
localStorage or cookies. One property is persisted: general.filter, via
host.applyJsonFilter.

LICENSING
Plan pareto-chart-pro-tcviz. getAvailableServicePlans() is called once and
cached; on failure the visual stays Free. Active and Warning accepted.
isLicenseUnsupportedEnv and isLicenseInfoAvailable respected: nobody is asked
to buy in Publish to Web, embedded or export. No licensing UI of our own, only
platform notifications. Production state: isPro from the licence manager.

FREE: the complete Pareto, minus the Pro items.
PRO: bin size 1-20%, outlier trimming, value labels, 3rd reference line, bar
border and gap.
