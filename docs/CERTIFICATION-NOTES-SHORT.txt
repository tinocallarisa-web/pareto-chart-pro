PLEASE READ FIRST - PRO PREVIEW (NEW IN 1.4.2.0)
Without a licence, IN EDIT MODE ONLY, a Pro setting the user turns on is drawn
WORKING under a "Pro preview" watermark naming it. Intentional, not missing
gating: it is how the user sees what they would be buying. In reading
view, before the licence resolves, and where licences cannot be read (Publish to
Web, embed, export) the FREE result is drawn, no watermark, no notice. The gate
is options.viewMode, not Desktop vs Service, and the preview is PER FEATURE,
only for the one actually turned on.

WHY THIS VERSION
Replaces 1.4.1.0. The Upgrade bar was overwritten: Power BI shows one
notification at a time and notifyLicenseRequired ran before notifyFeatureBlocked
in the same update(), so the banner wiped the purchase path. Order is now
clear -> banner -> (~10 s) Upgrade bar. Also: sorting declared implicit, and bar
border/width/gap are Free - the render never gated them, only the label was
wrong.

TESTING - FREE (no licence)
1. Entity + Value: 5 bars, cumulative line, 80% reference line.
2. Click a bar to cross-filter; Ctrl+click adds. Tab in, arrows, Enter, Escape,
   Shift+F10 for the menu. Bar color > fx is conditional formatting.
3. In EDIT mode set Bin size % to 5: 20 bars render under the watermark, the
   banner names it, and after ~10 s the Upgrade bar appears. Back to 20 and
   watermark, bars and notice all revert.
4. Reading view: 5 bars, no watermark, no notice.
With an active plan the same settings render with no watermark and no notice.

PRIVACY / NETWORK
No external calls, telemetry, CDN or endpoints; privileges: []. Licensing goes
through IVisualLicenseManager only, carrying no report data. No file access,
localStorage or cookies. One persisted property: general.filter.

LICENSING
Plan pareto-chart-pro-tcviz, matched on a Service ID ending in it. Requested
once and cached; on failure the visual stays Free. Active and Warning accepted.
isLicenseUnsupportedEnv and isLicenseInfoAvailable respected. No licensing UI
of our own.

FREE: the whole Pareto, 20% bins, 2 reference lines, conditional formatting,
bar border and gap. PRO: bin size 1-20%, outlier trimming, value labels, 3rd
line.
