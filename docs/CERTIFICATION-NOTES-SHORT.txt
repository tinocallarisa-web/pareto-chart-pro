WHAT'S NEW IN v1.2.0.0:
1. Tooltips Field Well: Up to 10 custom measures in hover tooltips.
2. IBCS Mode: One-click International Business Communication Standards compliance (#404040 neutral bars, #000000 solid axis typography).
3. Big Data Scaling (150,000+ rows): Supports <30k rows natively (window data reduction) and 150k+ rows via DAX quantile column (e.g. [Grupo Pareto] = CEILING((RANKX(ALL(T), T[Sales], , DESC, Skip)/COUNTROWS(ALL(T)))*10, 1)).
4. Monotonic Pareto Math: Strictly descending bars & clean 10% labels (0-10%, 10-20%... 90-100%).
5. Instant Cross-Filtering: Category SelectionId deduplication eliminates DS0 query errors (<1ms response).

LICENSING & PRIVACY:
Native IVisualLicenseManager API via host.licenseManager. Deferred resolution via setTimeout(0) does not block render. No external network servers or telemetry.
