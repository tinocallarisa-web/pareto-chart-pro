RESUBMISSION — 1200.1.1.4 (Code Repository / package.json)
The previous submission was rejected because the repository package.json was not a
valid npm manifest: it had been overwritten with the internal manifest that pbiviz
writes inside the .pbiviz package, so it carried no name, no scripts and no
powerbi-visuals-tools dev dependency. It is now a proper project manifest — name,
version, repository, license, start / package / lint scripts, powerbi-visuals-tools
^7.0.3 and powerbi-visuals-utils-formattingmodel ^7.1.0 — and package-lock.json was
regenerated to match. The fix is on main and on the certification branch. Build with
npm install && npm run package. No visual behavior changed from 1.3.0.0.

PRIVACY / NETWORK
No external network calls. No telemetry, no analytics, no CDN, no custom endpoints.
All calculation and rendering is local. The only host API used is Microsoft's own
IVisualLicenseManager (getAvailableServicePlans), which carries no report data.
No local file access, no localStorage, no cookies. The visual persists one property,
general.filter, through the standard host.applyJsonFilter mechanism.

LICENSING
Plan ID: pareto-chart-pro-tcviz. Resolution is deferred with setTimeout(0) after the
first render, so it never blocks painting; on failure the visual stays on Free.
Source is in production state: isPro resolved by the licence manager, DEV_MODE false,
GUID without suffix.

FREE: full Pareto with cumulative line; 20% bins (5 bars); 2 reference lines;
conditional formatting (fx) and Threshold Colors; Tooltips field well (10 measures);
IBCS Mode; drilldown; cross-filtering and multi-select; keyboard navigation and
screen-reader labels; high contrast.

PRO: bin size 1-20% (up to 100 bars); outlier trimming; value labels; 3rd reference
line; bar border and gap styling.

ACCESSIBILITY
supportsKeyboardFocus is declared and implemented. Roving tabindex (the chart is one
Tab stop), arrows move between bins, Home/End, Enter/Space select, Ctrl+Enter adds,
Escape clears, Shift+F10 opens the context menu. role=listbox / role=option,
aria-selected, descriptive aria-labels. Tooltips open on focus as well as hover.
Visible focus ring with a forced-colors variant. High contrast via colorPalette.

DATA VOLUME
capabilities declares window count 30000; Power BI Service streams further segments
with fetchMoreData(true), verified at 500,000 entities with slicers re-ranking.
Desktop cannot stream segments and stops at 30,000. When Power BI stops short, the
visual shows an amber notice with the exact row count received — a Pareto always
spans 0-100%, so partial data would otherwise look normal.

CROSS-FILTERING
Clicking a bar applies a BasicFilter over every entity in the bin. Measured ceiling
is 10,000 entities per bar over a live connection; past that the visual declines and
asks the user to reduce the bin size, rather than filtering a subset silently.

RENDERING EVENTS
renderingStarted at the top of update(); every exit path calls renderingFinished or
renderingFailed, including the empty-data-view and segment-continuation returns.

TESTING
Free: bind a dimension to Entity and a numeric measure to Value; 5 bars render with
the cumulative line and an 80% reference. Click a bar to cross-filter. Tab in, use
arrows, press Enter. Format Pane > Pareto > Bar color > fx opens conditional
formatting. Format Pane > Threshold Colors colors bars by cumulative threshold.
Pro: with an active plan, set Bin size % to 5 (20 bars), then check outlier trimming,
value labels, the third reference line, and bar border/gap.
