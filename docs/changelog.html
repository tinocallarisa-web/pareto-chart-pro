Changelog

Every released version of Pareto Chart Pro, what changed in it, and what is planned next. The version you are running is shown in Power BI under Format Pane → About, or on the visual's AppSource page.

Releases

1.4.0.0 Current September 2026

Added

  • A way to act on the Pro features. Changing a setting marked (Pro) without a licence now raises Power BI's own notification, which carries a link to get one. It appears on each fresh change and not on a resize, a selection or a data refresh.
  • A notice when a trial or licence has lapsed. Your Pro settings stay saved in the report, so without one the chart would quietly go back to 20% bins with no value labels and nothing to explain the change. Power BI shows this only in edit mode, so people reading the report see nothing.

Changed

  • Pro settings are visible to everyone, each marked (Pro) in the format pane — bin size, outlier exclusion, bar border, bar gap, value labels and the third reference line. They used to be hidden from Free users, so there was no way to discover that the paid features existed. Setting one without a licence is stored and takes effect as soon as the licence is active.
  • A licence in its payment grace period keeps working. The check accepted only the Active state; the Warning state is equally usable, so a paying customer no longer drops to the Free tier while a payment issue is resolved.
  • Environments that cannot enforce licences no longer prompt to buy. In Publish to Web, embedded, national clouds and PDF/PowerPoint export a Pro customer reads as Free; there the chart renders the Free result without asking anyone to purchase what they may already own.

Removed

  • The Free: 20% bins — upgrade to Pro caption drawn inside the chart. Microsoft's guidance is that a visual should not display its own licensing UI, and the caption was a dead end: small grey text with nothing to click. The platform notification replaces it.

Fixed

  • The bar colour swatch went back to the default after you changed it. The chart applied the new colour while the picker kept showing #4472C4, which read as the setting not having been saved. The pane now shows the colour actually in force.
  • Repository manifest. package.json did not declare typescript, which failed AppSource certification policy 1200.1.1.4.
1.3.0.0 September 2026

Added

  • Conditional formatting on bar color — the fx rule dialog is now available on Format Pane → Pareto → Bar color. Power BI resolves the rule per entity; each bar takes the color of its top-ranked entity.
  • Threshold Colors — color bars by where they fall relative to a cumulative percentage threshold, with an optional highlight on the bin where the cumulative line crosses. Available in Free and Pro.
  • Keyboard navigation and screen-reader support — the chart is a single Tab stop; arrows move between bins, Enter/Space select, Escape clears, Shift+F10 opens the context menu. Bars expose role="option", aria-selected and a descriptive label, and tooltips now open on focus as well as hover. A visible focus ring includes a high-contrast variant.
  • Localizable display strings.

Changed

  • Adaptive layout — margins, font size and axis chrome scale with the viewport. On small tiles the axis titles, the right-hand cumulative axis and the Free badge are dropped and X tick labels are thinned, instead of overlapping.
  • Cross-filtering now uses a filter rather than selection identities, which removes the previous practical limit on how many entities a bar could filter. Clicking a bar filters every entity behind it, up to 10,000 — beyond that the visual declines and says which setting fixes it, rather than filtering a subset. See Performance & scale for the measured figures.
  • host.allowInteractions is honored before selection, keyboard activation and the context menu.

Fixed

  • Clicking a bar filtered by one entity instead of all of them. A bar representing 40 customers cross-filtered the report by 1. The bar dimming ran off local state, so the chart looked correct while the filter it emitted was not. Introduced in 1.2.0.0.
  • The partial-data warning never appeared. The flag that triggers it was hard-wired off, so when Power BI stopped short of the full dataset the visual drew a Pareto of a partial universe with no indication — and a Pareto always spans 0–100%, so it looks entirely normal. It now reports the exact number of rows received.
  • Power BI Desktop could hang on large models. The visual kept asking for more data in an environment that cannot stream it, without ever rendering. Three independent brakes now stop that loop.
  • The first click on a bar left it unmarked, requiring a second click.
  • Highlights arriving from other visuals were erased when the visual had no selection of its own.
1.2.0.0 31 August 2026

Added

  • Tooltips field well — bind up to 10 additional measures (Profit, Quantity, Margin %, Customer Count) and show them in the tooltips for both bars and cumulative-line dots.
  • IBCS Mode — one toggle in the Pareto card applies International Business Communication Standards styling: neutral charcoal bars (#404040), solid black axis typography, restrained grid contrast. Available in both Free and Pro.
  • 150,000+ entity support in Power BI Service — segment streaming with zero-allocation selection-ID generation.
  • Strict monotonic binning — remainder entities (n % bins) are assigned to the top bins, which guarantees strictly descending bars and clean interval labels (0–10%, 10–20%, …).

Changed

  • Dynamic bin adaptation on filtered data — when slicers reduce the row count below the requested bin count, the visual now adapts instead of rendering empty bars or a broken X axis.
  • Explicit measure role resolution — the primary measure is isolated from tooltip columns, so Pareto sorting stays correct even with several tooltip measures bound.

Fixed

  • Cross-filtering could fail with The DataSet 'DS0' contains a filter with duplicate columns. Selection IDs are now deduplicated per category; cross-filter response is sub-millisecond.
  • The visual could freeze while loading segments on queries smaller than one chunk.
1.1.0.0 5 August 2026

Added

  • Drilldown — bind a hierarchy to Entity and use the Power BI drill buttons; the Pareto recalculates at every level.
  • Tooltips on cumulative-line dots — entity range, cumulative %, and bin share.
  • Report / canvas tooltip support — the visual registers with the Power BI tooltip service.
  • High contrast mode — bars, line, axes, dots and reference lines switch to the system palette automatically.
  • New Formatting Pane API — migrated from enumerateObjectInstances() to getFormattingModel(). Pro-only settings are now hidden in the Free tier rather than shown disabled.
  • Reference-line labels at the top of the line, so they no longer collide with X-axis ticks.

Changed

  • Free tier bin size is now 20% (5 bars), previously 10% (10 bars).
1.0.0.3 17 July 2026

Added

  • First AppSource release: ranked bins, cumulative percentage line, up to 2 reference lines (3rd in Pro), Free/Pro licensing via IVisualLicenseManager, cross-filtering, multi-select, highlight dimming, right-click context menu, landing page, bar tooltips.
  • Pro: value labels on bars, outlier exclusion (top/bottom %), custom bin size 1–20%, bar border, gap and opacity styling.

Roadmap

Planned work, in rough priority order. No dates are promised — items ship when they are ready and have passed AppSource certification. If one of these matters to you, open an issue and say so; that is what moves things up the list.

Planned

  • Additional display languages beyond English. The string resources are in place; what remains is the translations.
  • Cross-filtering beyond 10,000 entities per bar. Power BI carries a filter as a list of values, and past roughly that many the query becomes too large to run comfortably — so today the answer is a smaller bin size. A range-based filter would sidestep the list entirely, but only when the ranking field is a column with one row per entity, and the visual cannot currently tell whether that holds.
  • Bin-level color aggregation. Under an fx rule a bar shows the color of its top-ranked entity. Averaging across the bin would represent it better on a gradient, at the cost of being an approximation rather than an exact mapping.
